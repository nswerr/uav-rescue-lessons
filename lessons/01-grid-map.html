任務基礎 ・ LESSON 01

把搜救區域變成格子地圖

無人機要去哪裡、哪裡不能飛，電腦都看不懂「山谷左邊那棟倉庫」。這篇先把真實的搜救區域切成格子，讓人、程式和 AI 用同一套座標溝通。

難度入門
閱讀10 分鐘
先備會寫 Python 串列

學習目標

  • 能用「列,欄」座標標出起點、待查點與禁飛格。
  • 能說明四方向移動與「每步成本相同」這兩個簡化假設。
  • 能把一張 8×8 地圖寫成 Python 資料。

一　為什麼要切成格子

真實的搜救區域是連續的：無人機可以停在任何一點、朝任何方向飛。這對人很直覺，對程式卻太自由了——可能的位置有無限多個，沒辦法一個一個檢查。

最常見的做法是把區域切成大小相同的方格，每一格只有兩種狀態：可以飛或不能飛。如此一來，「規劃路線」就變成「在格子之間找一條連續的路」，問題一下子就有限、可以計算了。

格子要切多細？

格子越小越接近真實地形，但格子數量會變多、計算變慢。期末專案的第一版先用 8×8＝64 格，目的是讓展示時看得清楚、改得動。

二　座標的寫法：先列後欄

本站所有講義都用 「列,欄」，而且從 1 開始：列是由上往下數，欄是由左往右數。例如「第 4 列第 1 欄」寫成 4,1。

名稱代號範例座標意義
起點S4,1無人機起飛的位置
待查點T4,8需要前往確認的位置，例如回報有人受困的地點
禁飛格深灰色1,4;2,4;3,4不能進入的格子，多個座標用分號分隔

下面就是期末提案用的範例地圖。第 4 欄有一排禁飛格，只在第 4、6、7 列留了缺口。

動手試試

點第 4 列第 4 欄，把它變成禁飛格，看看路線怎麼繞；再把第 6、7 列第 4 欄也封住，左右兩邊就完全隔開了。路線怎麼算出來的，下一篇會拆開講。

三　兩個簡化假設

只能上下左右移動

每一步只能移到相鄰的上、下、左、右一格，不走斜線。這樣「步數」就等於格子之間的曼哈頓距離（沒有障礙時），容易手算驗證。

每一步的成本都一樣

不管飛到哪一格，都算 1 步。真實世界裡逆風、爬升會更耗電，但第一版先不考慮，讓我們能專心確認「找路」本身是對的。

禁飛格可能代表什麼

高壓電塔、火場上空、管制空域、建築物。這些在格子地圖上都一樣：不能進入，也不能穿過。

四　把地圖寫成 Python

最簡單的表示法是記下大小、起終點，再用一個集合（set）存所有禁飛格。集合查詢「這格是不是禁飛」很快，之後寫 BFS 會常常用到。

ROWS, COLS = 8, 8
start = (4, 1)   # (列, 欄)，從 1 開始
goal  = (4, 8)
blocked = {(1, 4), (2, 4), (3, 4), (5, 4), (8, 4)}

def is_free(cell):
    r, c = cell
    inside = 1 <= r <= ROWS and 1 <= c <= COLS
    return inside and cell not in blocked

print(is_free((4, 4)))  # True：第 4 列第 4 欄目前開放
print(is_free((5, 4)))  # False：禁飛格
小心從 0 還是從 1 開始

Python 的串列索引從 0 開始，但我們給人看的座標從 1 開始。如果之後改用二維串列存地圖，記得在存取時減 1，並在畫面上顯示時加回來。

重點回顧

  • 把連續空間切成格子，找路問題就變成有限、可計算的問題。
  • 座標一律寫「列,欄」，從 1 開始，例如第 4 列第 1 欄是 4,1。
  • 第一版假設只能上下左右移動、每步成本相同。
  • 禁飛格用 Python 集合存放，用 is_free() 檢查是否可以進入。
